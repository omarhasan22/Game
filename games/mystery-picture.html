    📖 Instructions
    1. Choose roles: Partner A = Navigator 🧭, Partner B = Plotter 👆.
    2. The Navigator reads the next ordered pair (x, y) from the list.
    3. Start at the origin (0, 0). Move along the x-axis first: right if x is positive, left if negative.
    4. Then move parallel to the y-axis: up if y is positive, down if negative.
    5. The Plotter taps that spot. Check the Selected point box.
    6. Both partners agree? Press “We agree – Plot it!”
    7. Switch roles after Point 5.
    8. The points join automatically. Plot all 10 to reveal the mystery picture!

    How do the signs of the coordinates help you identify the correct quadrant?

    • What happens to a point if you swap x and y, e.g. (2, 6) and (6, 2)?
